# 💻 Minha Primeira Página Web

Projeto desenvolvido como parte dos meus estudos em Front-End, construído e adaptado de forma autônoma para consolidar fundamentos de desenvolvimento web.

## 🚀 Sobre o Projeto
Esta aplicação web foi estruturada utilizando conceitos essenciais de programação front-end. Durante o desenvolvimento, customizei o escopo original aplicando novas paletas de cores, tipografia personalizada e adicionando botões de interação dinâmicos utilizando JavaScript.

## 🛠️ Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **CSS3:** Estilização, design responsivo e customização visual.
* **JavaScript:** Adição de interatividade e comportamento dinâmico nos botões.

## 🎯 O que aprendi / Destaques
* Autonomia na pesquisa de soluções e correção de problemas de código sem o material de apoio original.
* Manipulação do DOM com JavaScript para interações do usuário.
* Organização e versionamento de código no Git/GitHub.
